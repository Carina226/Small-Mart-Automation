- S = Small
- M = Medium
- L = Large

The size classification represents an initial relative effort estimate for each use case.

## Related Requirements

- REQ = Functional Requirement
- NFR = Non-Functional Requirement

The related requirements identify which system requirements are addressed by each use case.
